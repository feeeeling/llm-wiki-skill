Agent Skill · MIT · bash + git

Compile once.
Keep current.

A persistent markdown wiki your coding agent writes. Not another RAG box that forgets the synthesis the moment the tab closes.

Install the skill Karpathy’s pattern

Obsidian is the IDE.
The agent is the programmer.
The wiki is the codebase.

RAG rediscovers.
A wiki compounds.

Upload files, retrieve chunks, answer, discard. Ask a question that needs five documents and the model hunts fragments from scratch every time. An LLM wiki sits between you and the sources: pages already cross-linked, contradictions already flagged, synthesis already on disk.

Two gates. Git never waits.

  1. Hard. check-drift.sh compares compiled_rev to HEAD, intersects tracked paths, opens a ticket. No model.
  2. Soft. Next read — or /wiki-lint — the agent patches mapped pages, closes the ticket, advances the SHA.

Querying a stale wiki is blocked. Committing code is not.

Start

  1. 01 
    git clone git@github.com:feeeeling/llm-wiki-skill.git
mkdir -p .agents/skills
ln -s "$(pwd)/llm-wiki-skill" .agents/skills/llm-wiki
  2. 02 
    bash llm-wiki-skill/scripts/init-wiki.sh ~/my-wiki
cd ~/my-wiki && git remote add origin git@github.com:<you>/<wiki>.git
  3. 03 
    cp templates/source.yaml ~/my-wiki/sources/my-repo.yaml
bash ~/my-wiki/scripts/install-hooks.sh /path/to/code-repo

Works with Pi, Claude Code, Codex, and any Agent Skills host. Hooks do not travel with GitHub — run install on each machine.
